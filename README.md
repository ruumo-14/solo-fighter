# SOLO FIGHTER

2D横視点アクション × ローグライク育成のブラウザゲーム。Vercelで配信し、Supabaseをオンライン機能の基盤にするプロジェクトです。

## 現在の実装（初期プロトタイプ）

- 固定画面の2D横視点バトル、左右移動、ジャンプ、攻撃、コマンド、一時停止
- 6分間の通常戦闘と、2分・4分・6分のボス出現。各ボスの制限時間は60秒、最終ボス撃破でクリア（最大7分）
- 敵の時間経過・ステージ進行による強化、経験値、ステージ内レベルアップ、スキル3択
- ノーマル／レア／エピック／レジェンドのスキル表示、小ボスのレア以上スキル選択
- 魔晶の獲得、プレイヤー／キャラクター／ステージ内レベルの分離
- キャラクター選択・育成・レベルリセット、ペット・装備・属性の画面
- 通常ガチャ／S1ガチャの排出率表示、バナー別100回天井、ガチャ結果のローカル保存
- プレイヤーLv.50で解放するハードモード（敵・ボスの耐久と敵の強さを増加）
- 初期20ステージの進行枠（クリアで次を解放。20ステージ目まで）
- キャラクターごとの固定移動速度と、スキルによる速度変化
- ミッション・ランキング・図鑑・チャット・マーケット・問い合わせ画面
- ゲストセーブ（ブラウザのlocalStorage）

一部の画面は現段階ではUI・ローカル試作です。オンラインチャット、実際のプレイヤー間売買、確定ガチャ、週次ランキング報酬、管理者操作、アカウント削除などは、信頼できるサーバー処理とSupabase接続を完了するまで有効化しません。画面があることと、オンライン機能が完成していることは同じではありません。

## ローカル実行

```bash
# index.html をブラウザで開く
```

## Vercel公開

1. GitHubリポジトリ `ruumo-14/solo-fighter` をVercelにImport。
2. Framework PresetはOther、Build Commandは空欄、Output Directoryは `.`。
3. Deploy。

静的HTMLのため、初期プロトタイプはビルドコマンド不要です。

## Supabase接続

1. Supabaseでプロジェクトを作成。
2. SQL Editorで `supabase/schema.sql` を実行。
3. `index.html` 内の `SUPABASE_URL` と `SUPABASE_ANON_KEY` を、SupabaseのProject URLと公開用 anon/publishable keyに設定。
4. Vercelに再デプロイ。

**service_role keyは絶対にブラウザやGitHubへ置かないでください。** anon keyは公開用ですが、RLSが正しく設定されている必要があります。

## オンライン対戦・経済機能を有効にする前に

通貨、ガチャ抽選、装備付与、マーケット決済、ランキングスコア、管理者権限、アカウント停止・削除は、ブラウザから直接書き換えられないようにSupabase Edge Functions等のサーバー側トランザクションに移す必要があります。チャットには通報・レート制限・禁止語対策も追加してください。

## 仕様メモ

- ゲーム内通貨：魔晶
- ステージ：2分、4分、6分にボス。各ボス60秒以内。最終ボス撃破でクリア、最長7分。
- スキルレアリティ：ノーマル（白）、レア（青）、エピック（黄）、レジェンド（赤）
- 装備レアリティ：ノーマル、レア、エピック、レジェンド、S1。S1はS1ガチャ限定。
- 属性：火・水・風・雷・光・闇。属性相性によるダメージ倍率は設けず、武器ごとの特殊効果に使用する。
- 通常ガチャ排出率：アイテム等50%、ノーマル10%、レア35%、エピック4%、レジェンド1%。
- S1ガチャ排出率：アイテム等50%、ノーマル10%、レア33%、エピック4%、レジェンド2%、S1 1%。
- 各ガチャは独立した100回天井。100回目はエピック以上から均等抽選。
- ハードモード：プレイヤーLv.50で解放。
- 初期ステージ数：20。アップデートで追加予定。
- キャラクターの移動速度はキャラクターごとに固定し、スキルのみで変化する。
- モード：ノーマル、ハード、エンドレス、タイムアタック。ミニゲームは後続開発。
